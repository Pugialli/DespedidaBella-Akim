# Jogos — Despedida de Solteiro/a da Bella & Akim

Site com os jogos criados para a despedida de solteiro/a da Bella e do Akim. Todos os jogos rodam direto no navegador, sem instalação, e são acessíveis pelo hub central em [`index.html`](index.html).

**Site publicado:** https://Pugialli.github.io/DespedidaBella-Akim/

---

## Jogos

### 🕵️ Code Nomes
`codenames_bellaakim.html`

Adaptação do jogo de palavras Codenames. Dois times se enfrentam: o líder de cada time dá uma dica de uma só palavra para que os colegas identifiquem as palavras certas no tabuleiro, evitando as do time adversário e a palavra proibida.

---

### 🔐 Mega Senha
`megasenha_bellaakim.html`

Versão digital do clássico Mastermind. Um jogador define uma senha secreta e o adversário tenta descobri-la em tentativas limitadas, recebendo dicas de posição e acerto a cada rodada.

---

### 🥁 Trechos de Carnaval
`trechos_carnaval_bellaakim.html`

Ouça o trecho de uma música de carnaval e adivinhe o nome da música ou do bloco. Quem reconhece mais, leva!

## Tecnologia

Sites estáticos em HTML, CSS e JavaScript puro — sem dependências externas nem servidor. Fontes, imagens e texturas embutidas em base64 para funcionamento offline e deploy simplificado via GitHub Pages.

Todo o projeto foi desenvolvido com **vibecoding** assistido pelo [Claude Code](https://claude.ai/code) (Anthropic) — desde a geração dos jogos até o hub de navegação.
